# Machine Learning Practice Notebooks

This repository contains notebooks developed while learning core machine learning and deep learning concepts.

Topics covered include:

- Supervised learning (Logistic Regression, KNN, Naïve Bayes)
- Neural networks and deep learning with Keras
- Unsupervised learning (K-Means clustering)
- Natural language processing
- Medical dataset classification experiments

These notebooks were part of my foundational training before applying machine learning techniques to biomedical datasets such as clinical health data.
